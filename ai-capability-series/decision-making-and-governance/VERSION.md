# Version History

This document records the release history of this book as part of the **CloudPedagogy AI Capability Series**.

The books in this series are designed as stable, governance-ready references that may be updated periodically as practices, contexts, and evidence evolve. Versioning is used to ensure transparency, citability, and responsible reuse.

---

## v1.0 — Initial Public Release  
**Date:** 2026-02-02  

- First complete and stable release of this book  
- Content aligned with the CloudPedagogy AI Capability Framework (2026 Edition)  
- Structured for long-term reference, institutional use, and citation  
- Published in Markdown, PDF, and Word formats  

This version establishes the canonical baseline for the book. Future revisions will increment the version number and document substantive changes below.

---

## Versioning Policy

- **Major versions (v2.0, v3.0, …)**  
  Indicate significant conceptual changes, structural reorganisation, or major framework updates.

- **Minor versions (v1.1, v1.2, …)**  
  Indicate clarifications, expansions, corrections, or added examples that do not alter core intent.

- **Patch updates (v1.0.1, v1.0.2, …)**  
  Indicate minor edits such as typographical fixes or formatting corrections.

Each version is intended to remain publicly accessible for reference and citation.

---

## Citation and Use

When citing this book, please include:
- Book title

- Release date
