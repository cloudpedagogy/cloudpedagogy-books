# Capability-Driven Development

**Designing Responsible Human–AI Systems**

Capability-Driven Development (CDD) is a systems design methodology for building responsible and governable human–AI systems.

Rather than beginning with technological capabilities, CDD begins with **capability intent**: the human and organisational capabilities that systems are intended to support, preserve, or strengthen.

The method provides structured approaches for:

- defining the purpose and capability goals of a system
- clarifying human–AI responsibility boundaries
- identifying ethical, governance, and misuse risks
- embedding oversight mechanisms within system design
- evaluating system behaviour over time
- planning for responsible system evolution and retirement

CDD supports organisations that need to design AI-enabled systems that remain **accountable, inspectable, and governable** throughout their lifecycle.

# Method Overview

Capability-Driven Development follows a capability-first design sequence:

1. **Capability Intent**  
   Define the organisational capability the system should support.

2. **Human–AI Boundaries**  
   Clarify the division of responsibility between humans and automated systems.

3. **Ethics, Equity, and Risk**  
   Identify foreseeable harms, misuse scenarios, and equity impacts.

4. **Governance and Oversight**  
   Embed accountability structures and oversight mechanisms.

5. **System Architecture**  
   Design technical and workflow architectures consistent with governance requirements.

6. **Evaluation and Monitoring**  
   Track system behaviour and capability outcomes over time.

7. **Iteration and Change**  
   Adapt the system responsibly as organisational needs evolve.

8. **Retirement and Deprecation**  
   Plan for responsible system transition or decommissioning.

# Design Artefacts

CDD introduces a lightweight set of design artefacts that support responsible system development:

- System Capability Brief
- Human–AI Boundary Map
- Ethics, Equity, and Risk Notes
- Governance and Oversight Plan
- Evaluation and Learning Log
- Retirement and Transition Notes

These artefacts help organisations document key design decisions and maintain transparency about how human–AI systems operate.
