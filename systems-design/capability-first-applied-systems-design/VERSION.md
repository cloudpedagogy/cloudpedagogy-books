# Version History

This document records the version history of the Capability-Driven Development publication.

The book introduces Capability-Driven Development (CDD), a systems design methodology for building responsible and governable human–AI systems.

---

## Version 1.0  
2026-03-13

Initial public release.

Published on Zenodo:

https://doi.org/10.5281/zenodo.19009936

### Contents

This release introduces:

- the Capability-Driven Development design methodology
- the capability-first approach to human–AI system design
- the CDD design lifecycle
- core design artefacts supporting responsible system development
- guidance for governance-aware system architecture
- evaluation and monitoring approaches for AI-enabled systems
- lifecycle planning including iteration, change, and system retirement

### Design Artefacts Introduced

The following artefacts form the core of the CDD design toolkit:

- System Capability Brief
- Human–AI Boundary Map
- Ethics, Equity, and Risk Notes
- Governance and Oversight Plan
- Evaluation and Learning Log
- Retirement and Transition Notes

### Repository

Supporting materials and evolving documentation are maintained in the Capability-Driven Development repository:

https://github.com/cloudpedagogy/capability-driven-development
